# Contribuir

El código original usa GPL-3.0-only; revisá LICENSE y LICENSE-SCOPE.md.
Proponé cambios en un pull request con el problema, la solución y su verificación.
Identificá dependencias y material de terceros; conservá sus avisos originales.
No adjuntes claves, partidas privadas ni material de la tienda propietaria.

Antes de integrar un aporte se requiere aceptación expresa del CLA versión 1.0
incluido en CLA.md, identificando los commits cubiertos. El colaborador conserva
su copyright; el responsable puede integrar el aporte en la rama oficial bajo
GPLv3, sin una excepción para distribuirlo como software propietario. El CLA
no se aplica retroactivamente a código ajeno. Si se requiere acreditar identidad
o representación se coordina privadamente; nunca publiques DNI o domicilio.

Consultá README.md para las pruebas de cada repo. Para seguridad usá SECURITY.md.
Único contacto: contact@token-riot.com.
