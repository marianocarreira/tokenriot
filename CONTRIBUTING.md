# Contributing

Original software uses GPL-3.0-only. Read LICENSE and LICENSE-SCOPE.md before
contributing. Describe the problem, proposed solution and validation in a pull
request. Identify third-party material and retain its original license notices.
Never submit credentials, private saves, customer data or proprietary store files.

Before merging a contribution, explicit acceptance of CLA version 1.0 in CLA.md
is required, identifying the covered commits. Contributors retain copyright;
the maintainer may integrate contributions into the official project under
GPLv3 without an exception for proprietary distribution. The CLA does not apply
retroactively to someone else's work. Identity or organizational authority, when
needed, is verified privately; do not publish identity documents or addresses.

Run the checks described in README.md. Use SECURITY.md for vulnerability reports.
Repository documentation is maintained in English only. Product interfaces
support English, Spanish and Simplified Chinese.

Sole project contact: contact@token-riot.com.
