# TOKEN RIOT — human character concepts

Prepared for the website and future merchandise. These images reinterpret the original game sprites as fictional adult human characters; they do not replace the pixel-art sprites used by the game.

- Nano: black cap and hood, black technical layers, cargo trousers, backpack, gloves and high-top sneakers.
- Pili: black/pink cap, blonde ponytail, pink crop top, yellow technical cargo trousers, black utility details and black/pink/cyan sneakers.

Generation method: built-in ImageGen with each original sprite sheet as its costume reference. Transparent background; full-body editorial streetwear direction; natural human anatomy; no weapons or added logos.

These are character/art-direction concepts, not production garment patterns, print-ready separations or proof of merchandise availability. Website integration is pending.
