# Seguridad

Reportá vulnerabilidades de forma privada a **contact@token-riot.com**, único
correo de contacto del proyecto. Indicá versión o commit, impacto y pasos mínimos
para reproducirlo. No incluyas claves, datos de compradores ni datos personales
innecesarios. No publiques secretos o exploits sensibles en issues.

El servidor Node del juego está diseñado para uso local en loopback. Los tokens
son virtuales y el almacenamiento local no constituye una autoridad de pagos.
La tienda y su backend de pagos son proyectos propietarios separados.

La publicación fue revisada mediante escaneos de archivos y pruebas automatizadas;
esto no garantiza ausencia de vulnerabilidades. Las auditorías internas y el
historial previo de desarrollo no forman parte de esta publicación.
